게임 소개
Archery는 어떤 게임인가 이동, 자동 공격, 선택 성장으로 완성되는 한 판

Archery는 플레이어가 이동과 회피에 집중하고, 자동으로 발사되는 화살과 레벨업 스킬 조합으로 던전 스테이지를 돌파하는 모바일 탑다운 로그라이트입니다.

MOVE

조작은 가볍게

플레이어는 방향키 이동에 집중합니다. 공격 버튼을 줄여 모바일에서도 바로 전투 흐름에 들어갈 수 있습니다.

AUTO

공격은 선명하게

가장 가까운 적을 자동으로 겨냥합니다. 단순한 입력 안에서도 위치 선정과 타겟 우선순위가 살아납니다.

BUILD

성장은 매번 다르게

레벨업마다 다른 스킬 후보가 나타나고, 선택한 조합에 따라 전투 방식이 달라집니다.

SURVIVE

회피 중심 전투

적의 접근 방향과 투사체를 읽고 빈 공간을 찾아 이동합니다. 전투의 긴장은 손가락 하나의 움직임에서 시작됩니다.

CLEAR

방 단위 클리어

한 방의 적을 정리하면 포탈이 열리고, 다음 Map Object로 이어지며 짧은 성취가 반복됩니다.

POWER

스킬 조합의 상승감

공속, 탄수, 오브, 배럴이 쌓이면서 처음에는 피하던 적을 직접 밀어내는 순간이 생깁니다.

Tag = 행동 카테고리

Tag 하나당 “이 적이 무엇을 할지” 한 가지

  • 역할 · Melee / Ranged / Boss
  • 이동 · Follow / Pattern / Random
  • 공격 · MeleeAttack / Shoot / FlyingShoot
  • 속성 · Fire / Ice / Poison / Lightning ...

여러 Tag를 켜면 그만큼의 모듈이 자동으로 따라옵니다.

새 Enemy 추가

코드는 한 번만 짜고 데이터만 늘립니다

  • JSON에 스탯 한 줄과 켤 Tag를 적습니다.
  • Identity SO에서 Prefab과 모듈 설정을 골라 끼웁니다.
  • 나머지(어떤 컴포넌트가 붙을지)는 Factory가 Tag를 보고 알아서 처리합니다.
